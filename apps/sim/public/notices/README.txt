ControlAnything third-party notices

Conservative installed runtime dependency closure (dependencies, installed optional dependencies and installed peers) of the Quest, companion, sim, server and shared protocol/control packages, plus the browser-imported emulator packages; supplemental icon attribution and vendored asset notices. This is not a list of modules proven present in every browser bundle, nor all development tools in package-lock.json.

Generated by scripts/bundle-third-party-notices.mjs from the pinned installed packages, existing vendored asset notices and pinned official upstream supplements. Full notice bytes are preserved. See index.html or index.json for package versions, source filenames, inclusion reasons and SHA-256 hashes. Existing notices outside this directory are preserved.

Regenerate: node scripts/bundle-third-party-notices.mjs
Verify: node scripts/bundle-third-party-notices.mjs --check
The generator uses only local files and Node built-ins. It does not install, fetch, delete, build or deploy.
